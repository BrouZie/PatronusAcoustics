# Array Geometry & Beampattern

## Physical Array

The acoustic array uses a dual-ring design with 16 MEMS microphones:

| Parameter | Outer Ring (Ring 1) | Inner Ring (Ring 2) |
|---|---|---|
| Radius | 0.34 m | 0.17 m |
| Elements | 8 | 8 |
| Azimuth spacing | 45° | 45° |
| Chord spacing (adjacent) | 0.260 m | 0.130 m |
| Vertical offset | 0.20 m below outer |

The 2:1 radius ratio gives the inner ring a half-wavelength sampling at twice the frequency of the outer ring, extending the alias-free bandwidth.

## Beampattern (Conventional DAS, Boresight-steered)

Computed via `src/beampattern.py` using far-field delay-and-sum with plane-wave steering at boresight (az=0°, el=90°). The array response is evaluated on a full-sphere grid (1°×1°) and normalized to 0 dB at the peak.

### Beamwidth vs Frequency

| Frequency (Hz) | Azimuth BW (deg) | Elevation BW (deg) | Wavelength (m) | D/λ (outer) |
|---|---|---|---|---|
| 400 | 180.0 | 35.5 | 0.858 | 0.40 |
| 600 | 180.0 | 23.0 | 0.572 | 0.59 |
| 800 | 180.0 | 17.0 | 0.429 | 0.79 |
| 1000 | 180.0 | 13.5 | 0.343 | 0.99 |
| 1500 | 180.0 | 9.0 | 0.229 | 1.49 |
| 2000 | 180.0 | 7.0 | 0.172 | 1.98 |
| 2500 | 180.0 | 5.5 | 0.137 | 2.48 |
| 3000 | 180.0 | 4.5 | 0.114 | 2.97 |

**Key observations:**

- **Azimuth BW is 180° at all frequencies** — the circular array is azimuth-invariant (no left/right discrimination). A single station cannot resolve azimuth; triangulation with multiple stations is required.
- **Elevation BW narrows monotonically** from 35.5° at 400 Hz to 4.5° at 3 kHz. For a circular aperture of diameter D=0.68 m, the Rayleigh criterion predicts BW ≈ λ/D radians (half-power). At 1 kHz (λ/D ≈ 0.5 rad ≈ 29°), the measured 13.5° is narrower than the uniform-aperture prediction because the coherent summation from all 16 elements improves the effective aperture.

### Front-Back Rejection

FB rejection (response at 180° az, 90° el relative to boresight):

| Freq (Hz) | FB_rej (dB) |
|---|---|
| 400 | -9.5 |
| 600 | -4.6 |
| 800 | -0.2 |
| 1000 | -1.2 |
| 1500 | -3.0 |
| 2000 | -5.3 |
| 2500 | -0.3 |
| 3000 | -3.1 |

The non-zero FB rejection arises from the 5° array tilt, which breaks the vertical symmetry: mics on the forward side of the tilt sit at a different z-height than mics on the rear side, creating an asymmetric phase response between the front and back hemispheres. The variation is frequency-dependent (interference between the tilted array and the bore sight steering vector).

### Maximum Sidelobe Level

MSLL is 0.0 dB at all frequencies — conventional DAS on a circular array produces no sidelobes above the main-lobe level for a boresight-steered beam. The power falls off smoothly away from the steering direction.

## Array Manifold & Spatial Aliasing

The inter-element spacing determines the spatial Nyquist limit:

| Ring | Avg. spacing | Alias-free limit |
|---|---|---|
| Outer (adjacent) | 0.260 m | f < c / (2 × 0.260) ≈ 660 Hz |
| Inner (adjacent) | 0.130 m | f < c / (2 × 0.130) ≈ 1320 Hz |
| Cross-ring (nearest) | 0.170 m (radial) | f < c / (2 × 0.170) ≈ 1010 Hz |

For conventional DAS, grating lobes appear when the inter-element phase delay exceeds π. The dual-ring design pushes the first alias to a higher frequency than a single ring of either radius would achieve alone — the inner ring fills the spatial sampling gap at its scale.

## Wind Noise Coherence Baseline

Wind noise coherence between adjacent mics (Corcos model, default wind speed 1.5 m/s):

| Frequency (Hz) | Adjacent-pair coherence |
|---|---|
| 20 | 0.23 |
| 50 | 0.04 |
| 100 | 0.005 |
| 200 | 1×10⁻⁴ |
| 500 | < 1×10⁻⁸ |

Wind noise is effectively uncorrelated between any pair of mics above 100 Hz at the compact array scale. Without a windscreen, forward and rear mics show identical coherence (symmetry). A one-sided windscreen would reduce rear-mic coherence with the forward set.
